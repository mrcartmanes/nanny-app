# Приёмка «Где был»

Статус: не проводилась. Нужны собранный APK и реальный Android телефон с GMS.
Этот документ описывает процедуру; результаты измерений не подставлены.

## Функциональные сценарии

1. Чистая установка: пройти объяснения разрешений, выдать точное местоположение;
   фоновый доступ запрашивается отдельно. Повторить с отказом уведомлений и движения.
2. Нажать «Старт», заблокировать экран на 15 минут. Должен появиться один визит
   с началом по первой точке остановки. Наличие уведомления и точек подтвердить
   через Database Inspector в debug сборке.
3. Уйти более чем на 50 м: после двух внешних точек визит закрывается последней
   точкой внутри, в ленте появляется дорога. Одиночный GPS выброс визит не закрывает.
4. Повторить остановку в известном месте: используется прежнее место, без дубликата.
5. Потерять сигнал на 15 минут: визит остаётся открытым. Более 30 минут: визит
   закрывается последней известной внутренней точкой. После появления сигнала — новый кластер.
6. Свернуть приложение, выгрузить экран из последних, повторно открыть: запись
   и таймер сохраняются. Завершить процесс без force-stop и проверить восстановление.
7. Нажать «Стоп» из уведомления: визит закрывается, новые точки не добавляются.
   После повторного старта пауза между сеансами не становится дорогой.
8. Перезагрузить телефон во время записи: появляется предложение продолжить,
   нажатие открывает приложение и возобновляет запись. При отказе уведомлений — открыть вручную.
9. Переименовать место: все визиты изменили подпись. Объединить два места:
   все визиты ссылаются на выбранное место, исходное исчезло.
10. Изменить время завершённого визита. Неверный формат, окончание до начала,
    будущее и пересечение других визитов отклоняются. Удалить визит с подтверждением.
11. Визит через полночь: в каждом дне показана только его часть. Проверить границу
    месяца, недели и переход часового пояса/летнего времени при наличии такого сценария.
12. Сравнить суммы за день, неделю, месяц со скачанным CSV. Числовая сумма дробных
    минут должна совпасть со статистикой до округления интерфейса. Названия с кавычками,
    точкой с запятой, переносом строки и начальным `=` корректно открываются в таблице.
13. Без сети: запись работает, при неудаче Geocoder отображается «Место без названия».
14. Проверить светлую и тёмную темы, крупный шрифт, небольшой экран, поворот устройства.
15. Остановить запись, удалить все данные: места, визиты, точки, сеансы и файлы экспорта
    в кеше пусты. Повторный старт работает. Старые точки удаляются при запуске и в фоне.
16. Повторить ключевые сценарии на API 26, 29, 30, 33, 34 и 36, включая отзыв
    геолокации во время записи, отключённую геолокацию и недоступные Google Play Services.

## Суточная батарея

Нужно минимум одно контрольное измерение без приложения и одно с записью при
сопоставимом маршруте, связи, яркости и использовании телефона. Результат зависит
от устройства, состояния аккумулятора и покрытия. Во время измерения не заряжать
телефон; USB ADB может влиять на результат.

Перед началом, при доступности ADB:

```bash
adb shell dumpsys batterystats --reset
adb shell dumpsys battery
```

Через 24 часа:

```bash
adb shell dumpsys battery
adb shell dumpsys batterystats ru.gdebyl
adb bugreport gdebyl-24h.zip
```

Проверить отсутствие разрывов визитов при блокировке экрана, остановок службы,
дублирования и пропущенных остановок. Отдельно повторить на Xiaomi / Huawei / Samsung
с инструкцией энергосбережения. Артефакты bugreport содержат информацию устройства;
хранить локально, не добавлять в публичный репозиторий.

| Параметр | Результат |
|---|---|
| Модель / Android / прошивка | Не измерено |
| Версия APK и идентификатор сборки | Нет APK |
| Разрешения и режим батареи | Не измерено |
| Время начала / конца | Не измерено |
| Заряд начала / конца, контрольный день | Не измерено |
| Заряд начала / конца, запись включена | Не измерено |
| Расход приложения и разница с контролем | Не измерено |
| Непрерывность записи 24 ч | Не проверена |
| Порог ≤5% за сутки | Не подтверждён |
